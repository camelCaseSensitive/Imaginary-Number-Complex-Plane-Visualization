Where does √x go for x < 0?

A 3D picture of a real input x with a complex output y = Re(y) + Im(y)i.
y = √x
√(−1) = i
3D point: (x, Re(y), Im(y)) = (−1, 0, 1)
Real output: Im(y) = 0
Imaginary output: Re(y) = 0
Shared x-axis
This is an embedding of the function ℝ → ℂ into three real dimensions: (x, Re(y), Im(y)). For the principal square root, negative real inputs turn into positive imaginary outputs.
